### 6.3 批量写入

```python
# 追加一行（空表从 A1 开始，否则在最后一行之后）
ws.append(["姓名", "成绩"])
ws.append(["张三", 95])

# 批量追加多行：append_rows(rows, *, on_mismatch="warn")
# on_mismatch:
#   - "warn"（默认）：允许参差行，按每行实际列数写入；与首行列数不一致时发出 UserWarning
#   - "error"：严格矩形校验，不一致抛 ValueError，且不写入任何数据（原子）
#   - "ignore"：允许参差行，按实际列数写入，不提醒
ws.append_rows([["李四", 88], ["王五", 92]])

# 参差行示例（默认 warn）
ws.append_rows([["赵六"], ["钱七", 90, "A"]])

# 严格模式
ws.append_rows([["a", 1], ["b", 2]], on_mismatch="error")

print(ws.values)
print(ws.max_row)
print(ws.max_column)
print(ws.used_range.address)
```
